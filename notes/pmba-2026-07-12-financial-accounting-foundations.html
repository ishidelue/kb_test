核心概念 · Frameworks & Concepts

  • 三種價值 — Going-Concern / Book / Replacement Value
    價值類型 定義 衡量基礎 何時用
    營運價值
    Going-Concern Value    		 在「持續經營」前提下，企業未來現金流量的折現值 未來導向 · DCF 併購定價、投資評估
    帳面價值
    Book Value / Carrying Amount    		 依歷史成本入帳，減累計折舊／攤銷／減損後的餘額；公司整體帳面價值＝股東權益＝資產−負債 過去導向 · historical cost 財報表達、債務契約條款
    重置價值
    Replacement Cost    		 現在重新取得「同等效用」資產所需的支出 現在導向 · current cost 保險理賠、汰換決策、減損參考
  • 同一台設備、三個數字（例）：
    • 五年前購入超音波 NT$300 萬，直線折舊 5 年、已用 2 年 → 帳面價值 = 180 萬
    • 今天買同級新機需 NT$380 萬（通膨＋規格升級）→ 重置價值 = 380 萬
    • 該機支撐 POCUS/PSA 業務，年淨現金流 100 萬，折現後 → 營運價值 = 500 萬
  • 三者的差距來源：帳面 vs 重置 → 通膨與技術變動（historical cost 的相關性缺口）；帳面 vs 營運 → 未入帳的無形資產（品牌、團隊、流程、網路效應）。
  • Tobin's Q = 市值 ÷ 重置成本；Q > 1 表示市場認為公司能創造超過重置成本的價值 → 存在競爭優勢。
  • Liquidation Value（清算價值）是對照組 — 被迫拆賣的變現價格，只有在 Going Concern 假設不成立時才成為衡量基礎。

基本假設 · Assumptions（決定「怎麼記」的前提）

  • 假設 內容 為什麼重要／例子
    經濟個體
    Economic Entity    		 企業帳務與業主、其他個體分離 院長個人購車不得入醫院帳；反向地，合併報表把母子公司視為「單一經濟個體」
    貨幣衡量
    Monetary Unit    		 只記錄可用貨幣客觀衡量的事項，且假設幣值穩定（忽略通膨） 醫師團隊素質、品牌、平台用戶忠誠度不入帳 — 這是資產負債表最大的盲點
    期間
    Periodicity / Time Period    		 把連續的營運活動人為切成月／季／年報導 正因為要切期間，才需要 accrual、調整分錄與 cut-off；也才產生「認列時點」的爭議
    繼續經營
    Going Concern    		 假設企業於可預見未來將持續營運，不會被迫清算 這是 historical cost 的前提：因為會繼續使用，成本才能遞延（折舊、預付費用）。假設不成立 → 改按清算價值並強制揭露
  • 四者的邏輯鏈：Entity 界定「範圍」 → Monetary Unit 界定「可記錄的東西」 → Going Concern 讓成本「可以遞延」 → Periodicity 逼出「應計基礎」。

基本原則 · Principles（決定「記多少、何時記」）

  • Cost Principle（成本原則 / Measurement Principle）— 資產以取得時的交換價格入帳。優點為 verifiable、objective；代價是 relevance 低（不反映現值）。現行 IFRS 實為 mixed attribute model：部分項目（金融資產、投資性不動產）改用 fair value。這正是「帳面 ≠ 營運 ≠ 重置」的制度根源。
  • Revenue Recognition Principle（收入承認原則）— 傳統表述：收入於已賺得 (earned) 且已實現／可實現 (realized/realizable) 時認列。現行 IFRS 15 / ASC 606 改為控制權移轉予客戶時認列，採五步法：辨認合約 → 辨認履約義務 → 決定交易價格 → 依相對單獨售價分攤 → 履約時認列。核心口訣：收現 ≠ 認列收入。
    • 醫院：7 月看診即於 7 月認列收入（掛應收），健保 3–6 個月後撥款；核刪與浮動點值屬 variable consideration，應以最佳估計數入帳，非申報點數全額。
    • 平台：用戶儲值購買 Ag/Au coin 不是收入，而是 contract liability（預收／遞延收入），須待實際兌換使用才認列。
  • Expense Recognition / Matching Principle（費用配合原則）— 費用與其所產生的收入認列於同一期間。三種配合方式：(1) 直接因果（銷貨成本、醫材耗材）；(2) 系統合理分攤（折舊、攤銷）；(3) 立即認列（廣告、研發、多數管理費用）。註：研發立即費用化，正是新創帳面價值幾近於零的原因之一。
  • Full Disclosure Principle（充分揭露原則）— 凡足以影響使用者決策之資訊皆須揭露（報表本體＋附註＋補充資訊）。邊界由 materiality 與 cost-benefit 界定。例：或有負債（醫療糾紛訴訟）、關係人交易、期後事項、會計政策變動。

  • 四表勾稽 (articulation)：損益表的 Net Income → 流入權益變動表的保留盈餘 → 落入資產負債表的 Equity；現金流量表的期末現金 → 等於資產負債表的現金科目。四張表是同一組交易的四個投影，不是四份獨立文件。
  • 最重要的一句話：Profit ≠ Cash。損益表告訴你「有沒有賺」，現金流量表告訴你「會不會死」。黑字倒閉（帳上賺錢卻現金斷鏈）就是這兩張表分道揚鑣。

應用 · Application

  • 要衡量績效看損益表；要活下去看現金流量表；要賣掉公司／併購別人看營運價值，不是帳面價值。
  • 設備汰換決策：不要問「還沒折舊完，可惜」（sunk cost ＋ 帳面價值謬誤），要問「重置成本 vs 它未來能產生的營運價值」。

我的綜整 · My Synthesis（So what）

  • 醫院：健保收入的三個數字要分開管。申報點數 ≠ 認列收入（點值 × 核刪估列後） ≠ 實收現金（3–6 個月後）。ED 財務分析若直接拿「申報點數」當收入，等於同時違反 revenue recognition（未考慮 variable consideration）與現金流的現實。建議在 ED 損益模型裡三欄並列，把「時間差」與「打折率」變成可追蹤的 KPI。
  • 醫院：ART Center / ICU 設備投資。帳面價值近零的舊機器不代表「零成本繼續用」。決策基礎是 重置成本 與 它撐起的業務營運價值（PSA / POCUS 現金流）。用帳面價值做資本預算是最常見的財務誤判。
  • 醫院：Matching 原則的組織意涵。ED 人力成本是期間費用、幾乎立即認列；但醫師訓練與 credentialing 的收益是跨年的，會計上又無法資本化人才投資 → 制度性地，訓練投資在預算會議上永遠「看起來只是成本」。提案時必須自己補上未來收入端的估算，否則結構上就會被砍。
  • 新創（Spridea）：Monetary Unit ＋ Cost 原則是平台公司的結構性盲點。用戶、內容資產、網路效應都不進資產負債表，研發又立即費用化 → 帳面價值近乎零、營運價值可能很高。所以早期平台看 BS 沒有意義，要看 cohort retention、contribution margin、現金流。這也是 Tobin's Q > 1 的來源。
  • 新創：Ag/Au coin wallet 的會計設計要在寫程式時就決定。用戶儲值 = contract liability（預收），不是收入；只有在幣被實際兌換／消費時才依 IFRS 15 認列。未兌換部分（breakage）如何估列、何時認列屬實質判斷。技術面：wallet ledger 從 day 1 就要分「已儲值未使用」與「已消耗」兩個狀態 — 事後補不回來，且直接影響稅務與募資時的財報可信度。
  • 新創：Full Disclosure 的產品意涵。平台代幣制度愈不透明，使用者的信任成本愈高。揭露原則在平台商業模式裡不只是會計義務，而是信任基礎設施。

關鍵詞 · Key terms

  • Going-Concern Value — 持續營運下未來現金流量的現值
  • Book Value / Carrying Amount — 歷史成本減累計折舊、攤銷、減損後的帳面餘額
  • Replacement Cost — 現在取得同等效用資產所需的支出
  • Liquidation Value — 被迫拆賣時的變現價值；going concern 不成立時的衡量基礎
  • Tobin's Q — 市值 ÷ 重置成本；> 1 表示存在超額價值來源
  • Accrual Basis — 應計基礎；收入費用依「發生」而非「收付現金」認列
  • Variable Consideration — 變動對價（健保浮動點值、核刪）→ 以最佳估計數入帳
  • Contract Liability / Deferred Revenue — 已收現但尚未履約 → 是負債，不是收入
  • Materiality — 重要性；充分揭露的實務界線
  • Mixed Attribute Model — 現行 IFRS 同時採歷史成本與公允價值的混合衡量制度
  • Articulation — 四表勾稽
